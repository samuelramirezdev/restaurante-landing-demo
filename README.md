# 🍔 Landing Page para Restaurante - Burgers & Co.

Página web interactiva y adaptable (*responsive*) para negocios gastronómicos. Incluye menú filtrable y sistema de pedidos directo a WhatsApp.

## 🚀 Tecnologías utilizadas
* **HTML5:** Estructura semántica.
* **CSS3:** Diseño responsivo con Flexbox y CSS Grid.
* **JavaScript Vanilla:** Filtrado dinámico de menú e integración con la API de WhatsApp (`wa.me`).
